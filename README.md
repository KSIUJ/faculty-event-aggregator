# Faculty Event Aggregator

## 📖 Overview

Faculty Event Aggregator is a web application for collecting, managing, and displaying faculty events in a centralized platform.

## ✨ Key Features

* **Centralized Dashboard:**  All faculty events gathered in one place, easily accessible.
* **Smart Filtering:** Browse events by various criteria like topics, categories, or organizers.

## 🛠️ Tech Stack

* 🐍 **Backend:** FastAPI (Python)
* ⚛️ **Frontend:** React + Vite
* 🐘 **Database:** PostgreSQL
* 🐳 **Containerization:** Docker & Docker Compose
