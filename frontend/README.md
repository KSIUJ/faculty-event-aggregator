# Faculty Event Aggregator - Frontend

This is the frontend part of the Faculty Event Aggregator application, built with React and Vite.

## 🚀 How to run the application:

**Prerequisites:** You need to have Node.js version **22 or higher** installed. (You can use `nvm` to manage your Node versions).

1. Type in terminal:
```bash
cd frontend
```

2. Create the local environment file:
```bash
cp .env.example .env
```

3. Install dependencies:
```bash
nvm install 22
```

4. Run by typing:
```bash
nvm use 22
npm install
npm run dev
```

Note: Make sure your backend API is also running locally (usually on port 8000), otherwise the frontend won't be able to fetch the events!
